# Quick Fix: E2E Auth Token Role Path\n\n## Context\nThe CI/CD pipeline broke because the backend expects the `role` claim in the JWT token for authorization (due to `smallrye.jwt.path.groups=role` in `application.properties`). The previous fix updated the mock JWT with the `authenticated` role but placed it in the `groups` claim instead of `role`, causing the backend to reject requests to Google Drive integrations (401) and failing the E2E tests.\n\n## Solution\n1. Modify `generate_jwt.py` to use the `role` claim instead of `groups`.\n2. Regenerate the `mockJwt`.\n3. Update the hardcoded `mockJwt` token in all Playwright `.spec.ts` files.\n\n## Verification\n1. Ran the backend locally and verified `/api/integrations/google/accounts` no longer returns 401.\n2. Executed `npx playwright test` locally which successfully passed.
